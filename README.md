# チームの気分ログ

メンバーが毎日の気分を **5段階＋ひとこと** で記録し、週ごとの傾向を眺めるための小さなWebアプリです。

- ビルド不要の HTML / CSS / JavaScript のみ（依存ライブラリ・フレームワークなし）
- データはブラウザの `localStorage` に保存（閉じても残る／サーバーには送らない）
- 外部API・外部フォント・CDN も使いません

## 起動

ES Modules を使っているため、`index.html` をダブルクリックで開くのではなく、ローカルサーバ経由で開いてください。

**Node.js がある場合**

```sh
cd team-mood-log
npx serve -l 3000 .
# または: npm start
```

→ <http://localhost:3000> を開く

**Node.js がない場合（Python 3）**

```sh
cd team-mood-log
python3 -m http.server 3000
```

→ <http://localhost:3000> を開く

## テスト

記録の検証・追加/上書き/削除・読み込み時のマージ、週の集計、週ごとの推移、保存データの読み書きは、画面から切り離したモジュールにあり、Node.js 組み込みのテストランナーでテストしています（Node 20 以上）。

```sh
node --test
# または: npm test
```

## できること

- 名前・日付・気分（5段階）・ひとこと（80文字まで）を記録。同じ人・同じ日の記録は上書き
- 入力ミスは項目ごとに理由を表示（未入力、未来の日付、1年より前の日付、文字数オーバーなど）
- 週ごとの表示（月曜はじまり）：週の平均・前週比・記録数・いちばん良かった日
- メンバー × 曜日のマス目。マスにカーソル（スマホはタップ）でひとことを表示
- 気分の分布と、直近8週間の平均の推移（棒を押すとその週へ移動）
- 削除・すべて消去は「元に戻す」で取り消し可能、JSON で書き出し
- 書き出した JSON を読み込んで今の記録にまぜられる（同じ人・同じ日は更新が新しいほうを残す。読み込みも「元に戻す」可能）
- 記録がないときは「サンプルデータで試す」から雰囲気を確認できます
- ダークモード対応、`←` `→` キーで週を移動、`⌘/Ctrl + Enter` で記録

## ファイル構成

```
index.html        画面の骨組み
styles.css        見た目
src/core.js       中心ロジック（日付・検証・追加/上書き/削除・週の集計・推移）※DOMに依存しない
src/store.js      localStorage への保存と読み込み、JSON ファイルの読み込み（壊れたデータへの耐性つき）
src/sample.js     サンプルデータ
src/app.js        画面の描画とイベント
test/*.test.js    node --test 用のテスト
```
