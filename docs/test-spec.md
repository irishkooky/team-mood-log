# テスト仕様書 — チームの気分ログ（E2E / 画面テスト）

## 1. 目的

ブラウザ上でアプリを実際に操作し、README の「できること」に書かれた機能が期待どおりに動くことを確認する。
各テストケースの操作の様子を動画（webm）として残し、目視でも確認できるようにする。
動画は冒頭にテストID・名前・手順のチャプターが出て、カーソルの動きと操作した要素（赤い枠と点）が映り、最後に確認項目ごとの OK / NG が右下に表示される。

中心ロジック（検証・上書き・集計・保存）の細かい境界値は `test/*.test.js`（`node --test`）で確認済みのため、
本仕様書は **画面の表示と操作のつながり** に重点を置く。

## 2. テスト環境

| 項目 | 内容 |
| --- | --- |
| 対象 | `index.html`（`npm start` でローカル配信、既定 <http://localhost:3000>） |
| ツール | [Playwright CLI](https://www.npmjs.com/package/@playwright/cli)（`@playwright/cli`、devDependency）と公式 skill（`.claude/skills/playwright-cli`） |
| 撮影方法 | skill の video-recording に従った hero script（`e2e/hero.js`）を `playwright-cli run-code --filename` で実行。`page.screencast` で 1 ケース 1 本を録画 |
| ブラウザ | Chromium 系（Playwright CLI の既定） |
| 画面サイズ | 1280 × 800（TC-36 のみ 390 × 844）。動画も同じサイズ |
| 現在時刻 | **2026-11-20（金）12:00 JST から開始**（`page.clock.install`）。今週 = 11/16（月）〜 11/22（日）。「〜の続き」のケースへ移る間はページのタイマーを止め、トースト等が録画の切り替え中に消えないようにする |
| 動き | `prefers-reduced-motion: reduce` を指定（アニメーションによる結果のぶれを防ぐ） |
| 初期データ | 各ケースの前提に従い、`localStorage` を消去 or サンプルデータを読み込んでから録画を開始 |
| ファイル選択 | 「JSONを読み込む」はファイル選択ダイアログが CLI に横取りされるため、動画ではボタンにカーソルを合わせて選んだファイル名を表示し、ファイルはボタンの裏の `<input type="file">` に直接渡す |

## 3. 実行方法

```sh
# 初回のみ: 動画の保存に Playwright の ffmpeg が必要
npx playwright-cli install-browser ffmpeg

npm start              # 別ターミナルで起動しておく
npm run test:e2e       # e2e/run-e2e.sh を実行
# 別のURLで試す場合: BASE_URL=http://localhost:5000 npm run test:e2e
```

- 動画: `docs/test-videos/TC-xx_*.webm`（1 ケース 1 本、各 10〜20 秒・1〜2MB 程度。GitHub の PR にもそのまま添付できる）
- 実行結果: 下の各表の「結果」列（OK / NG）に自動で書き込まれる。確認項目ごとの詳細は `docs/test-results.md`

## 5. 対象外

- `localStorage` が使えない環境（プライベートモード等）での警告バナー — ブラウザ設定に依存するため手動確認
- Firefox / Safari での表示 — 必要に応じて `playwright-cli open --browser=firefox|webkit` で同じ手順を実行
- 検証・集計ロジックの境界値 — `npm test`（`test/core.test.js`, `test/store.test.js`）で確認
